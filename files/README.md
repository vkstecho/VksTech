# files folder

Put free downloadable files here (PDF, Excel, ZIP, etc.).

Then update the corresponding card in `downloads.html`:

```html
<a class="dl-card" href="files/your-file-name.pdf" download>
  <div class="dl-icon">🛠️</div>
  <div class="dl-title">Your Document Title</div>
  <div class="dl-desc">Short description of the file.</div>
  <div class="dl-foot"><span class="tag">PDF</span><span class="clink">Download →</span></div>
</a>
```

## Suggested files to add
- Metalliser PM checklist (PDF)
- Metalliser production / shift log (Excel or PDF)
- Any other shop-floor formats from your experience
