📌 Formula used
W (kg) = L (m) × Width (mm)/1000 × Thickness (μm)/1,000,000 × Density (kg/m³)

When you need this on the floor

  • Supplier sends a roll — verify claimed weight vs calculated weight
  • Dispatch needs kg for invoice / e-way bill
  • Costing: convert a length-based order into kg
  • Planning: estimate stock weight without weighing every roll

Step-by-step (with example)

Example: PET film, 10,000 m long, 1,500 mm wide, 12 micron.

  1. Open vkstech.com/calculators/film-roll-weight
  2. Select Film Type → PET (1380 kg/m³)
  3. Enter Length = 10000, Width = 1500, Thickness = 12
  4. Result appears instantly: ~248.4 kg

Density presets (built in)

  • PET — 1380 kg/m³
  • BOPP — 910 kg/m³
  • CPP — 900 kg/m³
  • LDPE — 920 kg/m³
  • Paper — 800 kg/m³

Wrong density = wrong weight. If your supplier quotes a different density, note it — the calculator uses industry-typical values.

Common mistakes

  • Entering width in metres instead of mm
  • Mixing up micron and GSM (use the GSM ↔ Micron tool first if needed)
  • Using PET density for BOPP (almost 50% error)
