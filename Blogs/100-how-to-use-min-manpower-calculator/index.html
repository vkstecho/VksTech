📌 Core idea
Relief = Roster days ÷ (Roster days − weekly offs)
Process headcount = ceil( on-duty crew × shifts × relief × (1 + buffer%) )
Shared headcount = ceil( (eng + supervisors + other) × relief × (1 + buffer%) )

When you need this

  • New line or new shift pattern
  • HR asks for “minimum sanctioned strength”
  • Checking if current roster is thin on weekends / offs

Step-by-step example

3 shifts · 1 weekly off · 7-day roster · 10% buffer · 4 machines × 2 people each · 1 engineer + 1 supervisor on duty per shift.

  1. Open vkstech.com/calculators/min-manpower
  2. Shifts 3 · Weekly offs 1 · Roster days 7 · Buffer 10%
  3. Relief shows ~1.167 automatically
  4. Machine qty 4 · People/machine/shift 2 → on-duty crew 8
  5. Engineers 1 · Supervisors 1
  6. Read total headcount (process + shared), rounded up

Common mistakes

  • Forgetting relief (planning only for on-duty numbers)
  • Zero buffer on a line with high absenteeism
  • Counting support staff once for the whole plant when they are shift-based
