How capacity is calculated

  1. Cycle time = Setup + Vacuum/Heat + Run time (jumbo÷speed) + Vent + Boat overhead
  2. Rolls/day = (1440 − cleaning minutes) ÷ cycle time
  3. Roll weight from width × length × micron × density
  4. Capacity = Rolls/day × Roll kg ÷ 1000 → MT/day
