Converting Plant Capacity

Rough MT/day for a converting line (or sum of identical lines) from web speed, width, thickness/GSM path and efficiency.

MT/day ≈ Speed(m/min) × Width(m) × 60 × Hours × Efficiency × GSM ÷ 1,000,000
—
Fill speed, width and GSM
MT/day

How to read the number

  • Speed = average sustainable speed, not nameplate peak
  • Efficiency = run time after changeovers, breaks and minor stops (often 70–85%)
  • For mixed products, run the calculator per SKU and weight by plan mix

This is a planning estimate. Metalliser capacity has its own tool because vacuum cycle and boat life dominate.
