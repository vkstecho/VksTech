# Career Journey – Image Galleries

Put company photos in the subfolders:

```
career-journey/
  uflex/     ← UFlex Limited, Noida
  jindal/    ← Jindal / JPFL Films
  gls/       ← GLS Polyfilms
```

## Naming rules (important)

**Option A – Simple numbers (recommended)**  
Name files: `1.jpg`, `2.jpg`, `3.png`, `4.webp` …  
They will display in sequential order (1, 2, 3…).

**Option B – Date in filename**  
If the filename contains a date (e.g. `2024-03-15-team.jpg`, `IMG_20250301.jpg`, `photo-2024-11-06.png`),  
images are sorted **newest first**.

Supported extensions: `.jpg` `.jpeg` `.png` `.webp` `.gif`

After uploading images, commit & push. The website picks them up automatically.
